# Vendored upstream sources

A working copy of pony-lsp and the `pony_compiler` bridge it uses, taken
unmodified from ponyc so that changes can be made and tested here and
applied upstream as one change rather than a series of them.

## Provenance

| | |
|---|---|
| Repository | `ponylang/ponyc` |
| Revision | `c67928519c2953c151812694d0521cbd88d2a24b` |
| Date | 2026-08-26 |
| Subject | Update release notes for PR #5872 |
| Working tree | clean at copy time |

Paths mirror the upstream layout, so `upstream/tools/pony-lsp/...` is
`tools/pony-lsp/...` in ponyc. Exactly the files `git ls-files` reported for
those two directories were copied, and nothing else.

## Producing the patch

The commit that introduced this directory contains the pristine copy and
nothing else, so everything since is the change:

    git diff <that commit>..HEAD -- upstream/

Applied at the root of a ponyc checkout with `git apply -p2`, or by
rebasing onto the revision above if it has moved on.

## One file is not upstream's to receive

`tools/pony-lsp/version.pony` is generated by CMake from `version.pony.in`
and is git-ignored in ponyc. It is copied here because the code does not
build without it, and it is ignored here too, so it never reaches a patch.
